# ICBINL (I Can't Believe It's Not Lua)

ICBINL is an ahead-of-time (AOT) compiled, systems-grade programming language that adopts Lua's clean, readable syntax layout while strictly enforcing systems-grade performance, static type safety, deterministic memory management, and zero garbage collection overhead.

## Documentation

For full details on syntax, types, pointers vs. references, memory layouts, and the complete EBNF grammar specification, please refer to the [Language Reference Specification](./doc/reference.md).
